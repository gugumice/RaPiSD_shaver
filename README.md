# RaPiSD_shaver
Bash script to automate resizing SD card image.
Requires GParted!
Must run with root privileges (sudo)!
For some reason resizing partition with GParted almost always ends with error in the first try so just repeat action.
It is advisable to leave some free space when resizing partition for normal system operation.
Intended for Raspberry PI images but should work for other as well.
